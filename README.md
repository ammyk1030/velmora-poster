A travel poster for Velmora, a place that does not exist: an isle of lanterns where the sky keeps its light. A pure-Python program that draws the poster and writes it as a PNG.

## Run it

```sh
python3 main.py
```

It writes `/output/entry.png` in the make.fun sandbox, or `entry.png` beside the program when run locally.
